# BIMteam — подбор event-подрядчиков

Сервис принимает условия мероприятия и показывает до трёх свободных подрядчиков с конкретными объяснениями. Это рабочая стартовая версия для HackAlem; дальше команда улучшает качество объяснений и интерфейс.

Абзал отвечает за сервер (`api/`, `core/`, `tests/`), Рустем — за интерфейс (`web/`). Пошаговая инструкция Git и план задач: [Как работать вдвоём](docs/TEAM_GUIDE.md). Формат обмена данными: [API](docs/API.md).

## Запуск на Windows

### Скачать и посмотреть сайт

**[Скачать актуальный сайт и сервер одним ZIP-архивом](https://github.com/BAITC-Hacks/hack-873d221c-bimteam/archive/refs/heads/main.zip)**

Ссылка всегда скачивает текущую общую версию из ветки `main`, включая новый интерфейс. Для закрытого репозитория войдите на GitHub под аккаунтом, которому выдан доступ (Абзал или Рустем). Если ссылка не открывается, скачайте через зелёную кнопку **Code → Download ZIP** на странице репозитория.

1. Скачайте ZIP и полностью распакуйте его через **Извлечь всё**.
2. Откройте полученную папку `hack-873d221c-bimteam-main`, в которой лежит этот README и `requirements.txt`.
3. В адресной строке Проводника введите `powershell` и нажмите Enter — терминал откроется в нужной папке.
4. Выполните команды ниже и откройте **[сайт на своём компьютере](http://127.0.0.1:8000)**. Терминал оставьте открытым, пока пользуетесь сайтом.

Это локальная версия: каждый запускает её на своём компьютере. Открывать `web/index.html` двойным кликом не нужно — для подбора требуется запущенный сервер. Ключ NVIDIA для просмотра и базового подбора не нужен. Git и Render для такого запуска тоже не требуются.

### Установка и запуск

Нужен Python 3.11 или новее. Проверьте `py -3 --version`: Python 2.6 не подходит. Если команда `py` не найдена, установите Python с python.org и заново откройте терминал.

В терминале из папки проекта:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn api.main:app --reload
```

Откройте http://127.0.0.1:8000 — приложение; http://127.0.0.1:8000/docs — страница для проверки запросов. Остановка сервера — Ctrl+C. Отдельный Node.js или npm не нужен. После первого запуска повторять установку не требуется, достаточно последней команды.

Linux/macOS: `python3 -m venv .venv`, затем `.venv/bin/python -m pip install -r requirements.txt` и `.venv/bin/python -m uvicorn api.main:app --reload`.

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

В активированном окружении также работает `pytest`. GitHub Actions запускает проверки после отправки ветки и создания PR. Тесты NVIDIA используют подставные ответы и не расходуют API.

## Подключение NVIDIA

Сначала убедитесь, что локальный режим работает. Скопируйте `.env.example` в `.env` только если `.env` ещё не существует. Заполните в редакторе:

```dotenv
NVIDIA_API_KEY=ваш_ключ
LLM_MODEL=точное_имя_доступной_модели_из_NVIDIA_Build
```

Не отправляйте ключ в чат, GitHub или файлы интерфейса. По правилам проекта секрет читается только из `.env`. Без обоих значений используется локальный режим.

Сервер обращается к [NVIDIA Chat Completions](https://docs.api.nvidia.com/nim/re/reference/llm-apis) по адресу `https://integrate.api.nvidia.com/v1/chat/completions`. В одном запросе модель выбирает короткие цитаты из описаний трёх уже отобранных профилей. Проверяем точное совпадение цитаты с исходным описанием. Неверный ответ, ошибка и ожидание больше 6 секунд возвращают локальное объяснение. Реальный API требует проверки с вашим ключом и доступной моделью.

## Как происходит подбор

1. Из 66 профилей выбираются нужные город и категория.
2. Исключаются занятые на дату, дороже бюджета, с неподходящим форматом, языком или длительностью. Пустой `max_hours` означает, что длительность присутствия не применяется.
3. Стартовое ранжирование — начальная цена по возрастанию, затем стабильный `id`. Это базовая версия; смысловое ранжирование пока не реализовано.
4. Возвращаются максимум три карточки. Объяснение содержит проверенные условия, а отдельная цитата раскрывает особенности профиля. NVIDIA не меняет порядок и ограничения.
5. Различаются три исхода: подбор успешен, категории в городе нет, кандидаты есть, но не подходят. Причины исключения могут пересекаться: один человек может быть занят и дороже бюджета одновременно.

Повторный запрос сохраняет порядок. Точный текст выбранной моделью цитаты может отличаться. Цена — «от» за мероприятие, не окончательное предложение. Календарь известен только с 23.09.2026 по 31.12.2026; другие даты отклоняются.

## Данные и ограничения

`data/contractors.csv` — выданные организаторами 66 анонимизированных event-профилей; поля-списки разделены `|`. Имеется 13 синтетических профилей, 18 восстановленных цен и 8 восстановленных городов. Отметки показаны на карточках. Предыдущий строительный пример сохранён в `data/legacy/construction-sample.csv` и сервисом не используется.

Бронирование, авторизация, платежи и обучение модели не входят в эту версию. Перед защитой улучшите персональность объяснений, проверьте NVIDIA и измерьте полный ответ с API: целевой ориентир ТЗ — до 10 секунд. Сценарии: [демо](docs/DEMO.md).

## Где что лежит

| Путь | Назначение |
| --- | --- |
| `api/main.py` | Принимает запросы страницы, отдаёт ответы |
| `core/catalog.py` | Читает и преобразует CSV |
| `core/recommend.py` | Проверяет условия и выбирает кандидатов |
| `core/nvidia.py` | Обращается к модели, проверяет цитаты |
| `web/` | HTML, стили и действия на странице |
| `tests/` | Автоматические проверки |
| `docs/` | Инструкция команде и описание API |
