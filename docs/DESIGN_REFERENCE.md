# Каталог и поиск: референс Airbnb

Референс: https://ru.airbnb.com/ (просмотрен 23.09.2026).

На главной изучены общая округлая панель поиска, компактная навигация, визуальные карточки, категории, активное состояние сегмента поиска и раскрытие календаря. Применены эти приёмы компоновки и взаимодействия; длительности анимаций ниже выбраны для нашего интерфейса, а не измерены на Airbnb.

## Реализация

- Поиск в горизонтальной панели; на мобильном — компактная сетка полей.
- Кастомные окна выбора города, формата, категории и даты на нативном dialog. На мобильном окно открывается снизу. Escape закрывает окно, фокус возвращается к кнопке.
- Исходные name, id, значения полей и события input/change сохранены. Календарь использует date_min/date_max из API, выбирает одну дату и поддерживает стрелки, Home/End и Page Up/Down. При отсутствии dialog остаются нативные поля.
- Карточки в три, две или одну колонку в зависимости от ширины. SVG-иллюстрации категорий созданы для проекта и явно подписаны. Фото подрядчиков, рейтинги и проценты совпадения не выдумываются.
- Быстрый выбор категории меняет только категорию, сохраняет остальные условия и запускает подбор. Прежние примеры запросов сохранены.
- Движение: открытие окна 280 мс, реакции кнопок 200 мс, подъём обложки 350 мс, появление карточек 500 мс с шагом 70 мс. Общая кривая cubic-bezier(.22,1,.36,1). Поддерживается prefers-reduced-motion.
- Тема «Сигнал», сохранение условий, сброс, смена даты на день и мобильная кнопка продолжают работать.

## Проверка

25 тестов pytest, node --check для трёх JS-файлов, git diff --check. В браузере проверены обе темы, сетка 1280 px, мобильный экран 375 px, выбор города и даты, клавиатура календаря, максимальная дата и заблокированный следующий месяц, сброс, бюджет 700 000 ₸, пустой результат, раскрытие профиля. Ошибок JS в проверенной странице нет. Полный аудит WCAG и всех мобильных браузеров не проводился.


## Журнальное оформление мероприятий

Дополнительные референсы: https://alexcollierdesign.com/wedding-planner-websites-that-book-luxury-clients/, https://carissacorsievents.com/, https://soeventful-swfl.com/.

Светлая тема использует молочный фон, шоколадный текст и оливковые акценты. В hero и поясняющих заголовках — Cormorant Garamond; форма и карточки сохраняют Manrope. Добавлен асимметричный первый экран с изображением, ссылка на поиск и блок процесса с крупным фрагментом сервировки. Поиск, календарь и API не менялись. Название сервиса — «Той таңдау»; векторный знак и favicon — лента-бант.

Изображение web/media/celebration-editorial.jpg создано встроенным imagegen как иллюстрация атмосферы, не как работа реального подрядчика. В обоих местах использования есть явная подпись. Размер 1536 × 1024, JPEG 88, 318281 байт. Основное изображение загружается приоритетно, нижнее — лениво; размеры заданы для стабильности вёрстки. Стоковые изображения из референсов не копировались.

Проверены 375 и 1280 px, обе темы, загрузка изображения и отправка формы с текущими условиями пользователя. Горизонтального переполнения и ошибок JS не обнаружено. 25 тестов pytest прошли. Новые стили учитывают prefers-reduced-motion.


## Панель выбора города

По присланному скриншоту Airbnb выбор города оформлен списком с авторскими линейными SVG-иконками, описаниями и отметкой выбранного города. Варианты берутся из исходного select, заполненного API. Геолокация и отсутствующие в каталоге направления не имитируются.

На компьютере диалог привязан к полю «Где» и ограничен размерами окна; при недостатке места может открыться над полем. На мобильном сохраняется панель снизу. Поиск игнорирует регистр и пробелы по краям, для пустой выдачи есть отдельное состояние. Стрелки переводят фокус между вариантами, Enter выбирает, Escape и клик вне панели закрывают окно и возвращают фокус. Выбор вызывает прежние input/change, сохраняя контракт API и сохранение условий.

Проверено в браузере: фильтрация по части названия, отсутствие результатов, клавиатурный выбор, Escape, закрытие снаружи, передача города в запрос без изменения остальных условий, обе темы и ширина 375 px. Ошибок JavaScript и горизонтального переполнения не обнаружено. Синтаксис JS и git diff --check проверены.
