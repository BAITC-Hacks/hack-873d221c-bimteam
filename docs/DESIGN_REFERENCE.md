# Каталог и поиск: референс Airbnb

Референс: https://ru.airbnb.com/ (просмотрен 23.09.2026).

На главной изучены общая округлая панель поиска, компактная навигация, визуальные карточки, категории, активное состояние сегмента поиска и раскрытие календаря. Применены эти приёмы компоновки и взаимодействия; длительности анимаций ниже выбраны для нашего интерфейса, а не измерены на Airbnb.

## Реализация

- Поиск в горизонтальной панели; на мобильном — компактная сетка полей.
- Кастомные окна выбора города, формата, категории и даты на нативном dialog. На мобильном окно открывается снизу. Escape закрывает окно, фокус возвращается к кнопке.
- Исходные name, id, значения полей и события input/change сохранены. Календарь использует date_min/date_max из API, выбирает одну дату и поддерживает стрелки, Home/End и Page Up/Down. При отсутствии dialog остаются нативные поля.
- Карточки в три, две или одну колонку в зависимости от ширины. SVG-иллюстрации категорий созданы для проекта и явно подписаны. Фото подрядчиков, рейтинги и проценты совпадения не выдумываются.
- Быстрый выбор категории меняет только категорию, сохраняет остальные условия и запускает подбор. Прежние примеры запросов сохранены.
- Движение: открытие окна 280 мс, реакции кнопок 200 мс, подъём обложки 350 мс, появление карточек 500 мс с шагом 70 мс. Общая кривая cubic-bezier(.22,1,.36,1). Поддерживается prefers-reduced-motion.
- Тема «Сигнал», сохранение условий, сброс, смена даты на день и мобильная кнопка продолжают работать.

## Проверка

25 тестов pytest, node --check для трёх JS-файлов, git diff --check. В браузере проверены обе темы, сетка 1280 px, мобильный экран 375 px, выбор города и даты, клавиатура календаря, максимальная дата и заблокированный следующий месяц, сброс, бюджет 700 000 ₸, пустой результат, раскрытие профиля. Ошибок JS в проверенной странице нет. Полный аудит WCAG и всех мобильных браузеров не проводился.
