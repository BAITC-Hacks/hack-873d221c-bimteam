# Проверяемое обоснование рекомендаций

`core/explanations.py` формирует обоснование на сервере, после жёсткой фильтрации.
Порядок рекомендаций и формат API не меняются.

- Уникальность языка проверяется среди всех свободных на дату профилей нужной
  категории и города, включая тех, кто не проходит бюджет и остальные ограничения.
- Уникальность полного совпадения проверяется по всем прошедшим условия профилям,
  до ограничения выдачи тремя карточками.
- Минимальная цена сравнивается со всеми прошедшими условия; при равенстве цен
  используется формулировка «одна из самых низких».
- Разница между бюджетом и начальной ценой не называется гарантированной экономией.
  Восстановленные цены помечаются в тексте, длительность учитывается при её указании.
- Локальный выбор цитаты оценивает предложения по словам, связанным с форматом,
  опытом и особенностями работы. Это эвристика, не смысловое ранжирование кандидатов.
  Предложения с отрицаниями сохраняются целиком; фразы не обрезаются ради лимита.
  Если нет короткого фрагмента, дополнительных характеристик не придумываем.

Сведения описания подаются как заявления автора профиля, а не независимо
подтверждённые достижения. Число гостей не входит в текущую форму запроса:
упоминание масштаба из описания не означает проверку вместимости под запрос.
NVIDIA по-прежнему может выбрать отдельную проверенную цитату `profile_excerpt`;
числовые сравнения и текст `explanation` остаются детерминированными.

Проверки: `pytest`, включая `tests/test_explanations.py`.
