# Сценарий защиты: пять запросов за две минуты

Истина — [data/demo_queries.json](../data/demo_queries.json). Запросы и ответы найдены скриптом из данных; ручных выдуманных ID нет. После изменения CSV или весов выполните scripts/find_demo_queries.py и pytest, затем перезапустите сервер.

1. Алматы → Ведущий → конференция → 10.10.2026 → 1 300 000 ₸. Четыре подходят; показаны Джинбей, Сон Гоку, Хаул. Объясните, что фильтры уже исключили неподходящих, а код выбрал тройку.
2. Измените только дату на 07.11.2026. Теперь Джинбей, Хаул, Куррапика. Сон Гоку занят, поэтому заменён. Верните первую дату: порядок должен совпасть.
3. Астана → Флорист → конференция → 10.10.2026 → 300 000 ₸. Один Хаку; не дорисовываем ещё двух. Профиль синтетический из исходного набора, это видно в карточке.
4. Астана → Декоратор → конференция → 10.10.2026 → 1 300 000 ₸. В городе нет категории; сообщение указывает Алматы и количество 3.
5. Алматы → Ведущий → конференция → 05.12.2026 → 250 000 ₸. Все отфильтрованы. В API есть проверенная подсказка бюджета от 1 000 000 ₸. Текущий frontend показывает сводку; hints/funnel можно открыть через /docs.

Новый API использует found/no_category/all_filtered; текущая страница получает совместимые ok/no_category_in_city/no_matches. Это два представления того же результата, не разные алгоритмы.

## Перед выступлением

- Запустить тесты по README, проверить каждый пример через страницу.
- Без ключа честно сказать «объяснения из проверенных шаблонов».
- Для LLM заполнить .env локально, выбрать доступную модель, перезапустить сервер и прогреть через scripts/warm_cache.py. Проверить explanation_source=llm и второе время <300 мс; source=template означает fallback, а не успешный вызов модели.
- Если fallback закэширован до исправления ключа, выбрать новую папку CACHE_DIR и перезапустить. Старый кэш не удалять вслепую.
- Не заявлять о семантическом ранжировании, пока не построен совместимый индекс и не проверены реальные запросы.
- Не обещать бронирование или окончательную стоимость: даты и цены требуют подтверждения.
