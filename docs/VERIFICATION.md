## Что заменено и почему

- Старые `core/` и два тестовых файла прежнего алгоритма удалены; заменены модульным `app/` и новой проверкой поведения. Старые версии доступны в истории Git, до коммита `3995ded`.
- Созданы строгая воронка, скоринг, сравнительные факты, подсказки, необязательная семантика, общий SDK и файловый кэш, пять демо, установщики и документация.
- `api/main.py` сохранён как совместимый вход для старой команды запуска. `web/`, исходный CSV и пользовательские ключи не менялись; дополнительных синтетических профилей нет.
- Старый запрос распознаётся по event_format/budget и получает прежние имена ответа. Исключение budget=0 ограничено старым интерфейсом, чтобы сохранить его кнопку.
- В противоречии ТЗ «один вызов»/«один повтор» выбран один обычный batch и максимум одна коррекция внутри общего таймаута 8 с.
- Для защиты от ненумерических выдумок модель может соединять только целые проверенные факты. Это строже проверки одних чисел, ценой меньшей свободы формулировок.

4. Рустему проверить страницу у себя; при желании добавить отображение новых hints/funnel. Перенос в main завершён после дополнительной проверки, см. ниже.
