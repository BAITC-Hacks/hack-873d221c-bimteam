# Интерфейс «Точно к месту»

Рустем / BIMteam. Обычные HTML, CSS и JavaScript; отдельная сборка не нужна.
Запуск из корня проекта: `uvicorn api.main:app`, затем открыть `/`.
Контракт сервера: `docs/API.md`. Параметры и границы дат берутся из `/api/options`.
Карточки возвращает `/api/recommend`; интерфейс не ранжирует и не добавляет профили.

Реализованы адаптивная форма, необязательные язык и длительность, примеры запросов,
карточки с подтверждёнными объяснениями и цитатами, отметки синтетических и
восстановленных данных, причины исключения. Различаются отсутствие категории,
отсутствие подходящих по условиям и ошибка сервера. При запросе форма блокируется,
тайм-аут — 15 секунд. После ошибки можно повторить запрос. Ключей в браузере нет.

Проверено с API ветки setup/team-starter:
- ведущие в Алматы, корпоратив, 10.10.2026, 1 000 000 ₸: три карточки;
- флорист в тех же условиях: одна карточка с объяснением;
- бюджет 0: отсутствие совпадений с причинами;
- флорист, Зарубежье: отсутствие категории в городе;
- отключение сервера: сообщение о связи, сохранение условий и повторная попытка;
- узкий экран: форма и карточки располагаются в одну колонку.

Все 19 существующих тестов pytest прошли; JavaScript проверен через `node --check`.
Реальный NVIDIA API без ключа не проверялся; отображаются объяснения сервера.
