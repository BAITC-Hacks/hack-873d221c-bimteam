# Правила проекта

- Код фильтрует и ранжирует; LLM только выбирает и соединяет проверенные факты.
- Одинаковые запрос/данные/настройки/кэш дают те же карточки; elapsed_ms может отличаться.
- Сортировка: (-round(score, 6), id). На выходе никаких неупорядоченных множеств.
- Пользовательские сообщения на русском. Цена «от» не равна гарантированной стоимости.
- Секреты только из локального .env; ключи, описания и wishes не журналировать.
- pytest должен проходить без сети, без ключей и без чтения личного .env.
- Запуск: uvicorn app.main:app --no-access-log. api.main:app — совместимый старый вход.
- После изменения данных/скоринга: python scripts/find_demo_queries.py и pytest.
- web/ ведёт Рустем. Сохранять legacy-контракт event_format/budget и canonical event_type/budget_kzt.
- Не скрывать отсутствие модели/индекса; реальное API и SLA проверять отдельно от моков.
