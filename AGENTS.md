# Правила проекта

- Код должен быть детерминированным.
- Один и тот же запрос должен давать один и тот же порядок результатов.
- Все строки, предназначенные для пользователя, должны быть на русском языке.
- Секреты должны загружаться только из файла `.env`.
- Тесты запускаются командой `pytest`.
- Сервис запускается командой `uvicorn api.main:app`.
